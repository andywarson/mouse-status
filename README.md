# 鼠标状态

支持 Windows 11 x64。默认每 30 秒读取一次设备数据。

## 显示方式

- **任务栏状态条**贴在主屏幕任务栏的隐藏图标箭头左侧。上行显示电量，下行显示当前回报率或连接状态。点击状态条打开设置。任务栏空间不足时，可从普通托盘图标查看读数和设置。
- **桌面悬浮窗**可拖动，程序会记住上次位置。精简版显示设备名、读数和状态。完整版另有项目标签及最近一次查询时间。
- 在「设置 → 常规」独立开关悬浮窗和任务栏状态条，两处可以同时显示，也可以都关闭。
- 普通托盘图标仍可通过右键菜单切换模式、立即刷新、打开设置或退出。

## 外观

「设置 → 外观」提供 Material 3、Fluent 2 和石墨深色。可自选强调色，也可恢复预设色。选择 PNG、JPEG 或 BMP 后，应用将图片居中裁成方形缩略图并保存，可分别用于悬浮窗和任务栏状态条。

## 统计

「设置 → 统计」可查看最近 1 小时、24 小时或 7 天的设备历史。数据从新版第一次读取设备时开始记录，按设备区分，保存在当前用户的本地应用数据目录 `MaicongMouseStatus/history`。

- 电量折线图显示百分比变化。绿色线段表示读到充电状态的区间。累计下降以未充电期间相邻有效读数之间的下降百分点计算。
- 环形图按观测时长计算各回报率档位的占比。相邻有效读数之间的时间归到前一次读到的档位，关机、断连和较长采样间隔留空。蓝牙设备未报告回报率时，环形图显示无数据。

## 设备支持

- **迈从 2.4G**：使用 `3837:1018` 的本机接收器实测电量、回报率和充电状态。为同协议的 `3837:1014` 和 `3837:1016` 加入适配，暂未在本机用这两种接收器实测。不同协议的 2.4G 接收器需要单独适配。
- **蓝牙低功耗（BLE）**：在设置的「数据来源」中选择已配对设备。程序使用 Windows 检查连接状态，从设备公开的标准电池服务读取电量。蓝牙路径未实现厂商专有的充电状态和回报率读取。已用本机配对的 Logitech G603 验证设备可被发现以及未连接状态。
- **设备名称**：2.4G 使用接收器的 HID 产品字符串，蓝牙使用 Windows 返回的设备名称。设备没有提供名称时显示连接类型。
- **读取间隔**可在 5–300 秒之间调节。开启自启动后，Windows 会在登录时运行当前路径的程序。移动程序后，可从新位置打开程序并重新保存自启动设置。

## 编译

在源码目录打开 PowerShell，运行：

```powershell
.\Build.ps1
.\Build.ps1 -Test
```

- `Program.cs` 负责悬浮窗、托盘图标、刷新及模式切换。
- `TaskbarStatus.cs` 负责定位和显示任务栏状态条。
- `SettingsWindow.cs` 负责设置、设备选择和 Windows 自启动。
- `Appearance.cs` 负责显示偏好、主题和图片缩略图。
- `History.cs` 和 `StatisticsView.cs` 负责本地历史记录、统计口径和图表。
- `Receiver.cs` 和 `MouseProtocol.cs` 负责迈从接收器查询和解析。
- `BluetoothStatus.cs` 通过 Windows Bluetooth LE API 读取设备状态。
- `ProtocolTests.cs` 检查协议解析和刷新间隔。

协议资料见 [迈从 HID 协议记录](https://github.com/Vex9th/mouse-control/blob/main/docs/MCHOSE_PROTOCOL.md) 和 [微软 BluetoothLEDevice 文档](https://learn.microsoft.com/en-us/uwp/api/windows.devices.bluetooth.bluetoothledevice)。
